## 6. CSS Concepts Used

### CSS Selectors
Element selectors, ID selectors, class-independent element styling, pseudo-classes, and descendant selectors are used to style different website components.

### Color Scheme
CSS variables are used to maintain consistent colors throughout the website.

### Box Model
Margin, padding, border, and box-sizing properties are used to control spacing and element dimensions.

### Flexbox and Grid
Flexbox is used to align navigation elements, while CSS Grid organizes the skills section.

### Hover Effects
Hover effects and transitions improve the interaction of navigation links, skill cards, the profile image, and buttons.

### Responsive Design
Media queries adjust the layout, spacing, font sizes, and navigation for smaller screens.

### Typography
The Poppins font improves readability and gives the website a modern appearance.

## 7. Setup Instructions

## 9. Design Decisions

The website uses a dark background with purple and pink gradients to create a modern, professional appearance. Rounded cards, consistent spacing, readable typography, and subtle hover effects improve the visual experience.

Responsive media queries ensure the website remains usable on desktop, tablet, and mobile screens.

## 10. Limitations

- The contact form is a front-end design and does not send messages without additional functionality.
- Google Fonts requires an internet connection to load the external font.
- The website does not currently use a backend or database.
